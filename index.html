// Frequently Asked

Got questions?

How does local vs cloud routing work? +
MEDHAS runs a lightweight router on-device. Simple tasks — file management, OS control, wake word detection — execute entirely locally. Complex reasoning is forwarded to our encrypted mesh network only when needed, with zero data stored.
What data does MEDHAS collect? +
Zero. We practice strict zero-logging. Voice audio is processed locally and never stored. Cloud requests are AES-256 encrypted end-to-end and purged immediately after the session ends.
Which devices are supported? +
MEDHAS runs natively on macOS (M1/M2/M3/Intel) and Windows 11. Linux support is currently in closed beta.
Is it free? +
The core local model is free, forever. The ultra-fast cloud reasoning layer — for heavy code analysis and real-time web search — requires a MEDHAS+ subscription at a competitive rate.
